# Sprang Designer
Create your own sprang pattern quickly and easily.
This program is currently under development. 
I welcome user feedback and suggestions for improving the program.
[Report bugs here!](https://github.com/atelekes/Sprang_pattern_designer/issues)

##[Try it **online**](https://atelekes.github.io/Sprang_pattern_designer/app/)**
---

## Features

- **Cross-Platform**: Now it's available on **Windows** **Linux** and **macOS**.

- **Modern UI**: Comes with a much cleaner, user-friendly interface and a built-in **Night Mode**.

<img src="https://github.com/user-attachments/assets/63800e27-988e-472b-87d9-93057c81ee0c" style="max-width: 100%; height: auto;" alt="Sprang Designer Main Interface" />


- **Multi-Selection & Editing**: Select multiple charts or nodes to *move*, *delete*, *mirror* or *copy-paste* them easily.
  
- **Built-in Helper**: Includes an overlay with all keybindings
  
<img src="https://github.com/user-attachments/assets/0646b58e-0883-4e4e-bc28-7c21feef5af1" style="max-width: 100%; height: auto;" alt="Built-in Helper Keybindings" />

- **Improved Save System**:
  - Saves the full pattern regardless of your viewing or zoom position.
  - Generates a PNG image containing pattern metadata, which can also be used for loading patterns back into the app.
  - ⚠️️ **ATTENTION!** Do *not* send the PNG file via messaging apps (e.g. Messenger, WhatsApp, etc.), as they compress images in a lossy way and corrupt the saved pattern data. Always send the `.json` file or compress the PNG into a `.zip` archive.
    
 - **Interactive Row Tracker**: Darkens every row except the active one to help align your eyes while weaving.

<img src="https://github.com/user-attachments/assets/6a50b81d-54c3-4c27-8544-40c3d892c8d1" style="max-width: 100%; height: auto;" alt="Row Tracker Feature" />

## How to Run

1. Download the archive for your operating system from the **Downloads** section below.
2. Extract the `.zip` file to any folder.
3. Run the executable file (`Sprang_Designer.exe` on Windows, or the application binary on Linux/macOS). No installation required!

---

### 🍎 macOS Note (Unsigned Application)

Since this app is not signed with an Apple Developer certificate, macOS Gatekeeper will block it on the first launch with a warning like *"App cannot be opened because it is from an unidentified developer"* or *"macOS cannot verify that this app is free from malware"*.

To allow the app to run:

1. **First-time launch (Right-click method):**
   - **Right-click** (or `Control` + click) the `Sprang_Designer.app` file and select **Open**.
   - Click **Open** in the security confirmation dialog. *(You only need to do this once.)*

2. **System Settings method:**
   - Go to **System Settings** > **Privacy & Security**.
   - Scroll down to the **Security** section where you see a note about `Sprang_Designer`, and click **Open Anyway**.

[Here is a video which could help](https://www.youtube.com/watch?v=EE4tTIEoBlM)
